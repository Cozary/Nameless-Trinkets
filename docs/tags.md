Certain tags define how Trinkets behave in the mod.  

### `nameless_trinkets_tag.json`  
📂 *Location:* `data/nameless_trinkets/tags/items`  
- Determines which items the **Mysterious Trinket** can grant.  

### `recyclable_trinkets_tag.json`  
📂 *Location:* `data/nameless_trinkets/tags/items`  
- Specifies which items can be **recycled** into **Unknown Fragments**.
