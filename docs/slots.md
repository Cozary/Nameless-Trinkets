Currently the only way to add new slots is through the tools provided by Accessories mod.

??? failure "The following is currently removed but will be reintroduced in the future."

    Slots can be increased by using the **Mysterious Trinket**. When used, it grants a chance to unlock additional slots.

    Both the success rate and the maximum number of obtainable slots can be modified in `nameless_trinkets-common.toml`
