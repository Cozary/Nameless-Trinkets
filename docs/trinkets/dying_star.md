# Dying Star

## How it works:
The **Dying Star** trinket grants the following effect:

- Right-clicking a trinket on it will devour it and cause it to disappear. Giving the _Dying Star_ other trinkets increases a random attribute by a random amount.

## Configuration:
- **Is Enable**: Determines whether the trinket's effect is active or not.
- **Attribute Scaling Configuration**: Each attribute affected by the Dying Star can be individually configured using the following parameters:
  - **Max Value**: The upper limit the attribute can reach.
  - **Min Increase**: The minimum amount the attribute can increase when a trinket is consumed.
  - **Max Increase**: The maximum amount the attribute can increase when a trinket is consumed.

  These values can be set for each of the following attributes:

- `Armor`
- `Armor Toughness`
- `Attack Damage`
- `Attack Knockback`
- `Attack Speed`
- `Block Break Speed`
- `Block Interaction Range`
- `Explosion Knockback Resistance`
- `Entity Interaction Range`
- `Fall Damage Multiplier`
- `Flying Speed`
- `Knockback Resistance`
- `Luck`
- `Max Absorption`
- `Max Health`
- `Mining Efficiency`
- `Movement Speed`
- `Oxygen Bonus`
- `Sneaking Speed`
- `Submerged Mining Speed`
- `Sweeping Damage Ratio`
- `Water Movement Efficiency`

## Notes:
- Pressing **Left Ctrl** on the trinket's tooltip will show you all the attributes and their values.
