# Four Leaf Clover

## How it works:
The **Four Leaf Clover** trinket grants the following effect:

- When you kill an entity, it causes the entity's loot table to be rolled additional times, generating extra drops.

## Configuration:
- **Is Enable**: Determines whether the trinket's effect is active or not.  
- **extraLoots**: Configurable number of extra loot drops to be generated per kill.

## Notes:
- This affects all types of loot, including conditional drops.
- Each extra roll is randomized, meaning it's not a simple duplication of the initial loot.
