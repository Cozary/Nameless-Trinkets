# Nelumbo

## How it works  
The **Nelumbo** trinket grants the following effects:

- Allows the player to stand on **water** as if it were a solid block.
- Pressing Shift allows the player to dive.
- If the player dives below eye level he is propelled upwards.

## Configuration  
- **Is Enable**: Determines whether the trinket's effect is active or not.  

## Notes   
- This trinket only works when the player is not fully submerged in water (eyes in the fluid check).
