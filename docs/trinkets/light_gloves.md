# Light Gloves

## How it works:
The **Light Gloves** trinket grants the following effect:

- It modifies the player's mining speed when not under the sky.

## Configuration:
- **Is Enable**: Determines whether the trinket's effect is active or not.  
- **Mining Speed Percentage**: Determines the degree to which the player's mining speed is increased.
  
## Notes:
- Only applies when the sky is not visible, i.e. check the block above the player.
