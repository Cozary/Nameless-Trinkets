# Reforger

## How it works:
The **Reforger** trinket grants the following effect:

- It automatically repairs any damaged items in the player's inventory after a specified time interval.

## Configuration:
- **Repair Speed Seconds**: Sets the time interval between each repair action.
- **Repair Quantity**: Defines how much durability is restored on each repair.

## Notes:
- Does not affect items not in inventory, such as the armor section.
