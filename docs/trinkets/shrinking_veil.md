#Shrinking Veil

##How it works:
The **Shrinking Veil** trinket grants the following effects:

- Decreases size.
- Increases speed.

## Configuration:
- **Is Enable**: Determines whether the trinket's effect is active or not.
- **Shrink Scale Percentage**: The percentage by which the player's size is reduced.
- **Speed ​​Percentage**: The percentage of extra speed.
