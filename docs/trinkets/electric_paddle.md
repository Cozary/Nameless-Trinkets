#Electric Paddle

##How it works:
The **Electric Paddle** trinket grants the following effect:

- It increases the speed of the boat when you ride it.

## Configuration:
- **Is Enable**: Determines whether the trinket's effect is active or not.
- **Boat Speed Percentage Multiplier**: Adjusts the boat's speed by a set percentage.

## Notes:
- The boat's movement is modified based on the player's input (right, left, up, down).
