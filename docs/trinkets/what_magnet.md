# What Magnet

## How it works:
The **What Magnet** trinket has the following effect:

- The trinket causes entities near the player to be randomly repositioned. Each tick, nearby entities within a specified range are moved to a random position around the player.

## Configuration:
- **Is Enable**: Determines whether the trinket's effect is active or not.
- **Range**: The effective range in blocks which nearby entities are attracted to the player.
