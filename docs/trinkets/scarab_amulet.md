# Scarab Amulet

## How it works:
The **Scarab Amulet** trinket grants the following effects:

- Grants the player a speed boost when walking on sand.
- Prevents **Husk** from targeting the player.

## Configuration:
- **Is Enable**: Determines whether the trinket's effect is active or not.  
- **Speed ​​Multiplier Percentage**: Determines the extra speed applied.
