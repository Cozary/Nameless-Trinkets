# Ghast Eye

## How it works:
The **Ghast Eye** trinket grants the following effects:

- Increases the player's maximum health.
- Killing an entity grants regeneration.
- If the effect is already active, the duration is extended.

## Configuration:
- **Is Enable**: Determines whether the trinket's effect is active or not.  
- **Regeneration Time**: The base duration of the regeneration effect applied on kill.
- **Regeneration Level**: The level of the regeneration effect applied on kill.
- **Regeneration Extra Time**: The amount of time added to the regeneration effect if the player already has it.
- **Extra Hearts**: The extra health added to the player’s max health.
