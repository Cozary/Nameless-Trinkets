This is the configuration you can find in 📂 `config/nameless_trinkets-common.toml`.

> **New Trinket Slot Probability**  

> - "newSlotProbability": It is the probability when using a **Mysterious Trinkets** of obtaining a new *Trinket slot*.

> **Fragments from Trinket Destruction**  

> - "getFragments": Decides whether you get an **Unknown Fragment** when recycling a trinket.

> **Trinket Slot Settings**  

> - "maxTrinketSlots": The maximum number of *Trinket slots* obtainable.
> - "startingSlotQuantity": The initial number of *Trinket slots* at the start of the game.

> **FOV Disable Settings**  

> - "disableFOV": Decides whether to disable the player's FOV change when equipping a trinket that applies speed.
