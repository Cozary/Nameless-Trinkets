## Frequently Asked Questions

### Can I disable trinkets?
> **Answer:**  
> Yes, trinkets effects can be disabled through the configuration files. (This feature is available from version v1.7.0 onwards.)

### The "X" trinket is too powerful, could you nerf it?
> **Answer:**  
> In general, no. Unless there's a very specific case, I don't make nerfs. However, you can easily adjust its stats through the configuration files.

### Is it possible to modify the stats of trinkets?
> **Answer:**  
> Yes, each trinket has its own configuration file, so feel free to customize them as you like!

### Can I change the number of trinket slots or the percentage of the Mysterious Trinket?
> **Answer:**  
> Yes, both the number of trinket slots and the Mysterious Trinket percentage can be adjusted via the configuration files.

### Can trinket recipes be disabled?
> **Answer:**  
> Yes, you can modify or disable trinket recipes using [CraftTweaker](https://www.curseforge.com/minecraft/mc-mods/crafttweaker) mod.

### I'm experiencing issues with max health, how can I fix it?
> **Answer:**  
> You can resolve this by using the [Max Health Fix](https://www.curseforge.com/minecraft/mc-mods/max-health-fix) mod.
