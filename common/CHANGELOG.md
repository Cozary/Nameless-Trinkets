- Datapacks are now available on GitHub.
- Loot Table configuration added in Fabric
- (Fabric) LootTables are now modifiable via configuration.
- [Shrinking Veil] new trinket.
- [Titan's Mark] new trinket.
- [Woundbearer] new trinket.
- [Dying Star] new trinket.
- [Resonant Heart] new trinket.
- [Trinket Bundle] new item.
- [Cracked Crown] now display in detail the Stats it applies.
- [God's Crown] now display in detail the Stats it applies.
- [Fertilizer] now has an interval between activations
- [Fertilizer] Added new description
- [Dark Nelumbo] now no damage is taken from lava.
- [Sigil Of Baphomet] added config to modify added time and max time.

- Standardize value format: convert multiplications to percentages.
- (Fabric) Refactor: moved mixins logic to custom events.
- (Fabric) loot table logic moved.
- The chances of (Fabric) Loot Tables have been equalized with those of (NeoForge).
- "speedForceParticles" config value has been moved from the general configuration to the trinket's own configuration.
- (NeoForge) LootTables are now modifiable via configuration.
- [Cracked Crown] nerf. The attributes it applies have been substantially lowered.
- [God's Crown] nerf. The attributes it applies have been substantially lowered.
- [God's Crown] recipe.
- [Ghast Eye] nerf.
- [Miner's Soul] new texture.
- [Four Leaf Clover] new texture.
- [Dragon's Eye] new texture.
- [Light Gloves] new texture.

### Removed

- Trinket rendering.
- (NeoForge) LootTables can no longer be edited using DataPacks
- [God's Crown] loot table. Now it doesn't appear in chests.

### Fixed

- [True Heart Of The Sea] Not working properly.
