# Miners Soul

## How it works:
The **Miners Soul** trinket grants the following effect:

- When you break a block it generates loot by applying a higher enchantment level of Fortune than the current tool.

## Configuration:
- **Is Enable**: Determines whether the trinket's effect is active or not.  
- **Extra Looting Level**: The bonus level applied to the **Fortune** enchantment for generating extra loot drops.

## Notes:
- The **Miners Soul** trinket will not trigger loot generation for blocks that do not have a loot table (such as entity-based blocks).
- The **Miners Soul** enhances the loot generated from blocks that drop items, using the tool's **Fortune** enchantment and applying the **extraLootingLevel** bonus.
