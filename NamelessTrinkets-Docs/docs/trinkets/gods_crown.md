# God's Crown

##How it works:
The **God's Crown** trinket grants the following effect:

- The player gains additional modifiers to several stats:
	- **Maximum Health**
	- **Movement Speed**
	- **Fly Speed**
	- **Attack Damage**
	- **Armor**
	- **Attack Speed**
	- **Armor Resistance**
	- **Attack Knockback**
	- **Knockback Resistance**
	- **Luck**
	- **Block Range**
	- **Entity Range**
	- **Step Height Addition**
	- **Swimming Speed**
- The player's field of view modifier is set to **1.0F**, making it unaffected by other field of view changes.

## Configuration:
- **Is Enable**: Determines whether the trinket's effect is active or not.  
- **Modifiers**: Applied based on the indicated percentage.

## Note:
- In the settings, some attributes have the value 0.
- To disable FOV modification, go to `nameless_trinkets-common.toml`.
