# Pocket Lightning Rod

## How it works:
The **Pocket Lightning Rod** trinket grants the following effect:

- It triggers lightning strikes during thunderstorms around the player.

## Configuration:
- **Is Enable**: Determines whether the trinket's effect is active or not.  
- **Thunders**: Defines the likelihood of a lightning strike occurring.

## Notes:
- The lightning strike happens only during rainstorms when it is thundering, and the strike location is randomized based on the chunk the player is in.
