# Sleeping Pills

## How it works:
The **Sleeping Pills** trinket grants the following effects:

- Prevents the player from sleeping.
- The player gains `Night Vision` and `Weakness`.
- If the `Phantoms` get close to the player they will disappear.

## Configuration:
- **Is Enable**: Determines whether the trinket's effect is active or not.
- **Night Vision Time**: Determines the amount of time in ticks that `Night Vision` is applied.
- **Weakness Time**: Determines the amount of time in ticks that `Weakness` is applied.
- **Phantom Range**: Distance in blocks at which `Phantoms` disappear.
- **Bed Disabled**: Prevents players from using beds.
